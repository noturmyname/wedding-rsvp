# Свадебный сайт с RSVP

Красивый сайт-приглашение, где гости заполняют форму:
- ФИО
- С чьей стороны (жених / невеста)
- Будут ли присутствовать
- Количество взрослых и детей
- Имена детей, контакты, комментарии

Вы видите в админке точные цифры для организации (банкет, места и т.д.).

## Быстрый запуск

```bash
cd wedding-rsvp
./run.sh
```

или:

```bash
cd wedding-rsvp
PYTHONPATH=/root/.local/lib/python3.12/site-packages python3 app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

Админка: **http://127.0.0.1:5000/admin**  
Пароль по умолчанию: `wedding2026`

## Что изменить под себя

Откройте файл `app.py` и в начале найдите блок:

```python
# === НАСТРОЙКИ (измените под себя) ===
ADMIN_PASSWORD = os.environ.get("ADMIN_PASSWORD", "wedding2026")
COUPLE_NAMES = "Анна & Иван"
WEDDING_DATE = "15 августа 2026"
WEDDING_PLACE = "Загородный клуб «Усадьба», Подмосковье"
# =====================================
```

Поменяйте имена, дату, место и пароль.

## Как отправить гостям

1. Запустите сайт (см. выше).
2. Чтобы гости могли открыть его из интернета — нужно выложить на хостинг.

### Бесплатные варианты хостинга:

**Самый простой для Python:**
- [Render.com](https://render.com) (бесплатный тариф)
- [Railway.app](https://railway.app)
- [PythonAnywhere](https://www.pythonanywhere.com)

Или можно временно открыть доступ через ngrok / cloudflared tunnel, если хотите быстро показать друзьям.

## Экспорт

В админке есть кнопка **«Скачать CSV»** — файл откроется в Excel / Google Таблицах.

## Безопасность

- Смените `ADMIN_PASSWORD` и `SECRET_KEY` перед выкладкой в интернет.
- База данных — файл `rsvp.db` рядом с `app.py`. Делайте бэкапы.
