========================================
  КАК ЗАПУСТИТЬ СВАДЕБНЫЙ САЙТ
  (очень просто, даже если ты ноль)
========================================

1. Распакуй папку wedding-rsvp на рабочий стол.

2. Открой командную строку (или PowerShell):
   - Нажми Win + R
   - Напиши cmd и нажми Enter

3. Перейди в папку (пример):
   cd C:\Users\ТвоёИмя\Desktop\wedding-rsvp

4. Установи нужную библиотеку (один раз):
   pip install flask

5. Запусти сайт:
   python app.py

6. Открой браузер и зайди на:
   http://127.0.0.1:5000

Админка: http://127.0.0.1:5000/admin
Пароль: wedding2026

Чтобы остановить сайт — в окне cmd нажми Ctrl + C
